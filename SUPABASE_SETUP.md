## 🗄️ Create Database Schema

### Step 1: Open SQL Editor
1. In Supabase dashboard, go to **SQL Editor** (left sidebar)
2. Click **New Query**

### Step 2: Create Contacts Table
Copy and paste this SQL query, then click **Run**:

```sql
-- Create contacts table
CREATE TABLE IF NOT EXISTS contacts (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) NOT NULL,
  phone VARCHAR(20),
  message TEXT NOT NULL,
  status VARCHAR(50) DEFAULT 'new',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW())
);

-- Create index for faster queries
CREATE INDEX idx_contacts_email ON contacts(email);
CREATE INDEX idx_contacts_created_at ON contacts(created_at DESC);

-- Add comment
COMMENT ON TABLE contacts IS 'Contact form submissions from FitZone website';
```

### Step 3: Enable RLS (Row Level Security)
1. Go to **Authentication** → **Policies**
2. Select the `contacts` table
3. Click **New Policy**
4. Create policy for INSERT:
   - **Policy name**: `Allow public insert`
   - **Operation**: INSERT
   - **Target role**: anon
   - **Using expression**: (leave blank)
   - **With check**: (leave blank)
5. Click **Create policy**

### Step 4: Verify Table Creation
1. Go to **SQL Editor**
2. Run this query to verify:
```sql
SELECT * FROM contacts;
```

## 🔑 Get API Keys

### Step 1: Find Your Supabase URL
1. Go to **Settings** (gear icon) → **API**
2. Under **Project URL**, copy the URL
3. It should look like: `https://your-project-id.supabase.co`

### Step 2: Find Anon Public Key
1. Still in **Settings** → **API**
2. Under **Project API keys**, copy the **anon** key
3. It starts with `eyJhbGc...`

### Step 3: (Optional) Service Role Key
1. In the same section, you can see **Service Role** key
2. Used for server-side operations (more powerful, keep private)

## ⚙️ Configure Environment Variables

### Step 1: Update `.env` File
Open `d:\react\vite\gym\.env` and add:

```env
# Supabase Configuration
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key_here
VITE_SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here
```

**Replace with your actual values from Step 1 & 2**

## 👀 View Contact Data

### Option 1: Supabase Dashboard
1. Go to [supabase.com](https://supabase.com)
2. Login to your project
3. Go to **Table Editor** (left sidebar)
4. Select **contacts** table
5. You'll see all submitted contact forms

### Option 2: SQL Query
1. Go to **SQL Editor**
2. Run this query:
```sql
-- View all contacts
SELECT * FROM contacts ORDER BY created_at DESC;

-- Count contacts
SELECT COUNT(*) as total_contacts FROM contacts;

-- View contacts from last 7 days
SELECT * FROM contacts 
WHERE created_at >= NOW() - INTERVAL '7 days'
ORDER BY created_at DESC;

-- View only new contacts
SELECT * FROM contacts 
WHERE status = 'new'
ORDER BY created_at DESC;
```

## 📧 Optional: Email Notification

To send an email when someone submits a contact form:

### Step 1: Add Email Column
```sql
ALTER TABLE contacts ADD COLUMN email_sent BOOLEAN DEFAULT FALSE;
```

### Step 2: Create Function
```sql
CREATE OR REPLACE FUNCTION notify_admin_contact()
RETURNS TRIGGER AS $$
BEGIN
  -- Send email notification (requires email extension)
  PERFORM pg_notify('contact_submission', 
    json_build_object(
      'id', NEW.id,
      'name', NEW.name,
      'email', NEW.email,
      'message', NEW.message
    )::text
  );
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER contact_notification
AFTER INSERT ON contacts
FOR EACH ROW
EXECUTE FUNCTION notify_admin_contact();
```

## 🔄 Database Schema Details

### `contacts` Table Structure

| Column | Type | Description |
|--------|------|-------------|
| `id` | BIGINT | Unique identifier (auto-generated) |
| `name` | VARCHAR(255) | Visitor's name |

## 🛡️ Security Best Practices

### ✅ DO:
- [x] Keep API keys in `.env` (never commit)
- [x] Use Anon key for client-side operations
- [x] Enable Row Level Security (RLS)
- [x] Use Service Role key only on backend
- [x] Rotate keys periodically
- [x] Add validation on backend
- [x] Sanitize user input
- [x] Rate limit contact form submissions

### ❌ DON'T:
- [x] Don't expose Service Role key in frontend
- [x] Don't commit `.env` with real keys
- [x] Don't disable RLS
- [x] Don't trust client-side validation alone
- [x] Don't display sensitive table info to users

## 🐛 Troubleshooting

### Issue: "Error: Supabase credentials not found!"
**Solution**: 
1. Check `.env` file has both variables
2. Ensure variable names start with `VITE_`
3. Restart dev server

### Issue: "table contacts does not exist"
**Solution**:
1. Go to SQL Editor in Supabase dashboard
2. Run the CREATE TABLE query from above
3. Enable RLS policies

### Issue: "Operator does not exist: permission denied"
**Solution**:
1. Go to **Authentication** → **Policies**
2. Create INSERT policy for public/anon users
3. Select `contacts` table
4. Create policy with default settings

### Issue: "Cannot read property 'from' of undefined"
**Solution**:
1. Check Supabase credentials in `.env`
2. Make sure `@supabase/supabase-js` is installed
3. Run `npm install @supabase/supabase-js`

### Issue: Form submits but data not saved
**Solution**:
1. Open browser DevTools (F12)
2. Check Console for error messages
3. Check that RLS policies allow INSERT

## 📊 Advanced Queries

### Get statistics
```sql
SELECT 
  COUNT(*) as total,
  DATE(created_at) as date
FROM contacts
GROUP BY DATE(created_at)
ORDER BY date DESC;
```

### Get by status
```sql
SELECT COUNT(*) as count, status
FROM contacts
GROUP BY status;
```

### Search by email or name
```sql
SELECT * FROM contacts
WHERE name ILIKE '%john%' 
   OR email ILIKE '%@example.com%'
ORDER BY created_at DESC;
```

## 💡 Code Usage

### In React Component
```javascript
import { supabase } from './config/supabase'

// Insert data
const { data, error } = await supabase
  .from('contacts')
  .insert([payload])
  .select()

// Query data (admin component)
const { data: contacts } = await supabase
  .from('contacts')
  .select('*')
  .order('created_at', { ascending: false })

// Update status
await supabase
  .from('contacts')
  .update({ status: 'read' })
  .eq('id', contactId)
```
