## 🔧 3-Step Setup

### Step 1: Create Supabase Account
1. Go to [supabase.com](https://supabase.com)
2. Sign up and create a new project
3. Wait for setup to complete (2-3 minutes)

### Step 2: Create Database Table
1. Go to **SQL Editor** in Supabase
2. Copy this SQL and run it:

```sql
CREATE TABLE IF NOT EXISTS contacts (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) NOT NULL,
  phone VARCHAR(20),
  message TEXT NOT NULL,
  status VARCHAR(50) DEFAULT 'new',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW())
);

CREATE INDEX idx_contacts_email ON contacts(email);
CREATE INDEX idx_contacts_created_at ON contacts(created_at DESC);
```

### Step 3: Add API Keys to `.env`
1. Get your Supabase URL and Anon Key from **Settings → API**
2. Edit `.env` file in project root:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key_here
```

3. Restart dev server: `npm run dev`

## 💻 Code Usage

### In Components
```javascript
// Import Supabase
import { supabase } from '../config/supabase'

// Query data
const { data } = await supabase
  .from('contacts')
  .select('*')
  .order('created_at', { ascending: false })

// Insert data
await supabase
  .from('contacts')
  .insert([{ name, email, phone, message }])
  .select()

// Update status
await supabase
  .from('contacts')
  .update({ status: 'read' })
  .eq('id', contactId)

// Delete contact
await supabase
  .from('contacts')
  .delete()
  .eq('id', contactId)
```

## 🐛 Quick Troubleshooting

**Q: "Cannot read property 'from' of undefined"**  
A: Check `.env` has both `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`

**Q: "table contacts does not exist"**  
A: Run the SQL CREATE TABLE query in Supabase SQL Editor

**Q: Changes not reflecting after edit**  
A: Restart dev server with `npm run dev`

**Q: Supabase credentials not found**  
A: Restart dev server after editing `.env`
